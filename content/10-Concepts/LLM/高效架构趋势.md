# 高效架构趋势（YOCO / 线性注意力 / Muon）

> [!abstract] TL;DR 一句话直觉
> 【改成你的话：新一代 Flash 档模型的配方正在收敛——DeepSeek/MiMo 走 YOCO，Qwen/GLM 走稀疏-线性 3:1 交错，但 Muon 优化器和复杂残差是全员标配。】

## 它解决什么问题
标准 Transformer 推理成本高（KV-Cache 随长度线性膨胀）；新一代「Flash」档模型用混合架构把长上下文推理成本打下来。

## 工作原理（四大模型的配方对比）
- **DeepSeek V4.1 Flash 与 MiMo V3（同路线）**：YOCO 架构——预填充期间只有网络前半部分活跃，用于构建 KV 缓存表示；无线性注意力；配令牌级索引器
- **Qwen 3.8 Next Flash 与 GLM 5.3 Flash（同路线）**：3:1 交错（类似 Kimi K3）在稀疏注意力与线性注意力之间切换（GDN 与 KDA 两种机制）
- **共性**：DeepSeek/Qwen 使用 Engram；门控或下沉机制（GLM 5.3 Flash 例外，全/稀疏注意力层用无或部分 RoPE，参见 [[Positional Encoding 与 RoPE]]）；复杂残差网络（mHC 或门控残差）；**全部用 Muon 优化器训练**

## 关系
- **相关**：[[Transformer]]、[[KV-Cache]]（YOCO 的优化对象）、[[Positional Encoding 与 RoPE]]、[[MoE]]（同为降本路线）、[[MiMo 2.6]] 与 [[递归自我改进]]（GLM Flash 正是 RSI 案例的承载模型）
- **观察**：配方公开收敛说明高效架构的设计空间已被摸得差不多，下一轮分化可能在 Engram 类记忆模块
