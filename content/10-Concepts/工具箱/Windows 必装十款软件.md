# Windows 必装十款软件

> [!abstract] TL;DR 一句话直觉
> 【改成你的话：十款覆盖「找、截、传、卸、播、画、记、连、控、写」十个动作的 Windows 基本功软件，装齐后系统才顺手。】

## 清单（按功能记忆）
| 功能 | 软件 | 一句话 |
| ---- | ---- | ------ |
| 找文件 | Everything | 百万文件秒出结果；可索引 NAS 共享目录（选项→文件夹→添加，支持 Rescan） |
| 截图/OCR | PixPin | 长截图、OCR、贴图、像素级截图，国产免费 |
| 互传 | LocalSend | Win/Mac/Android/iPhone 直连对传 |
| 卸载 | Geek Uninstaller | 本体+残留一键清 |
| 播放 | PotPlayer | 格式通吃、字幕编码全扛 |
| 画质 | Upscayl | 开源 AI 老照片/低分辨率放大 |
| 知识库 | Obsidian | 插件生态即第二大脑（本 wiki 正跑在它上面） |
| 组网 | Tailscale | 异地设备拼成虚拟局域网 |
| 多机键鼠 | Deskflow | Win/Mac/Linux 无缝切换 |
| 写代码 | VS Code + AI 代理 | 搭 Codex/Kilo Code，提需求即出脚本 |
